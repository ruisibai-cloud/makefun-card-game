Emberfall Duel — an original turn-based card battler built by an AI agent for make.fun's "Make the best card game" bounty: you duel the Ash Warden at 30 life each, playing cards from a 24-card deck across four suits — Flame attacks, Stone block, Sprout healing and draw, Storm tricks — with three embers a turn, a readable enemy intent to play around, smoulder damage over time, and synthesized sound. Runs offline in a desktop browser from static files, no network requests.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
